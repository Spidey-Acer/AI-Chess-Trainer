# Sample Games

Place your PGN files here for analysis.

## How to Add Games

1. Download games from chess.com, lichess.org, or other platforms
2. Save them as .pgn files in this directory
3. Run `chess-trainer analyze <filename>.pgn`

## Sample PGN Format

```pgn
[Event "Casual Game"]
[Site "https://lichess.org"]
[Date "2025.01.20"]
[Round "?"]
[White "Player1"]
[Black "Player2"]
[Result "1-0"]

1. e4 e5 2. Nf3 Nc6 3. Bb5 a6 4. Ba4 Nf6 5. O-O Be7 1-0
```
