## 📝 Documentation Standards

All documentation in this project follows these standards:

1. **Markdown Format**: All docs use GitHub-flavored Markdown
2. **Clear Headers**: Hierarchical structure with emoji icons
3. **Code Examples**: Syntax-highlighted code blocks
4. **Cross-References**: Links between related docs
5. **Update Dates**: Major updates noted in CHANGELOG.md
6. **Accessibility**: Clear, simple language where possible

## 🔄 Keeping Documentation Updated

Documentation is maintained alongside code changes:

- **Code changes** → Update relevant technical docs
- **New features** → Update README, CHANGELOG, PROJECT_STATUS
- **Bug fixes** → Update TROUBLESHOOTING if user-facing
- **API changes** → Update API.md
- **UI changes** → Update COMPONENT_REFERENCE.md
